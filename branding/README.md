# EZlator 아이콘 자료

## 사용 중인 아이콘: 다크 버전
- 네온 하늘(`#00E5FF`) + 네온 분홍(`#FF2E88`) 알약형 조이패드, 배경 `#07070D`
- 앱에 들어 있는 파일: `app/src/main/res/`의 `mipmap-*/ic_launcher*.png`, `mipmap-anydpi-v26/ic_launcher*.xml`, `drawable/ic_launcher_background_pad.xml`, `drawable-nodpi/ic_app_logo.png`

## 예비: 라이트 버전 (`branding/light/res/`)
- 하늘(`#00BFE8`) + 분홍(`#FF2E88`), 알약 안쪽 흰색, 배경 `#F5F6FB`
- 바꾸는 방법: `branding/light/res/` 안의 폴더를 `app/src/main/res/`에 그대로 덮어쓰기 (파일 이름이 모두 같음)
- 메뉴 상단 판은 어두운 색이므로, 라이트로 바꿀 때 `drawable-nodpi/ic_app_logo.png`는 다크 버전을 그대로 두는 것도 방법임

## 원본 (`branding/source/`)
| 파일 | 내용 |
|---|---|
| `ezlator_icon_dark_1024.png` / `ezlator_icon_light_1024.png` | 둥근 사각형 완성 아이콘 1024px |
| `ezlator_mark_dark.png` / `ezlator_mark_light.png` | 배경 없는 조이패드 알약(README, 저장소 대표 이미지용) |

## 출처
- 이 프로젝트에서 직접 만든 그림임(사용자 러프 스케치 → 도형으로 제작). 다른 회사의 로고·상표 요소를 쓰지 않음.
